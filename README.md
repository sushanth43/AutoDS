# AutoDS

An Autonomous Data Science platform that automates the complete machine learning workflow.

## Project Vision

AutoDS is designed to help users automatically:

- Upload datasets
- Profile and clean data
- Perform Exploratory Data Analysis (EDA)
- Engineer features
- Train multiple Machine Learning models
- Compare model performance
- Explain predictions
- Generate reports
- Visualize results through an interactive dashboard
